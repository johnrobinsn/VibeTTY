## Full Description (max 4000 characters)

VibeTTY is an open-source SSH client designed for developers who code on mobile. Built on the trusted ConnectBot foundation, VibeTTY adds features specifically for "vibe coding" - AI-assisted development workflows.

**KEY FEATURES**

• Kitty Keyboard Protocol - Full modifier key support (Shift+Enter, Ctrl+arrows) for modern CLI tools like Claude Code
• ADB Port Discovery - Instantly find your wireless debugging port with one tap
• Port Forwarding - Create persistent SSH tunnels that remember their enabled state
• VibeBar - Compact keyboard panel optimized for terminal workflows
• Virtual Terminal Width - Render wider terminals with horizontal panning
• Profile System - Save and reuse terminal configurations across hosts
• Google Voice Keyboard Support - Dictate commands hands-free
• Multiple Sessions - Switch between connections seamlessly
• Extended Keyboard Protocols - tmux modifyOtherKeys support for advanced key combinations

**SECURITY**

• SSH public key authentication (RSA, Ed25519, ECDSA)
• Hardware security key support
• Per-key backup control
• Known host verification
• Biometric protection for private keys

**CONNECTIVITY**

• SSH and Telnet protocols
• Jump host / ProxyJump support
• Port forwarding (local, remote, dynamic SOCKS)
• Background connection persistence
• Wake lock for stable connections

**TERMINAL FEATURES**

• Full color support (256 colors, true color)
• Custom fonts and downloadable fonts
• Configurable color schemes
• Hardware keyboard support with Escape key remapping
• Horizontal scroll for wide terminals

**OPEN SOURCE**

VibeTTY is free, open-source (Apache 2.0 license), and respects your privacy. No ads, no tracking, no data collection. All your credentials stay on your device.
